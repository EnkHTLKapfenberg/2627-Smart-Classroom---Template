# Home Assistant

Hier werden projektbezogene Home-Assistant-Konfigurationen und gegebenenfalls selbst entwickelte Komponenten dokumentiert bzw. abgelegt.

Dokumentiert insbesondere:

- verwendete Entitäten,
- Namen und Einheiten,
- Gerätezuordnung,
- Availability/Status,
- relevante Automatisierungen,
- benötigte MQTT-Topics.

Keine Passwörter, Tokens oder andere Zugangsdaten committen.
