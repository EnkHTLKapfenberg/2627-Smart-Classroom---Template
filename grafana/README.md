# Grafana-Dashboard

Jede Gruppe erstellt ein eigenes Dashboard für ihr Smart-Classroom-Teilsystem.

## Ziel

Das Dashboard soll nicht nur Rohwerte darstellen, sondern die Frage beantworten:

> Welche Informationen benötigt ein Benutzer, um anhand unserer Messdaten den Zustand des Klassenzimmers beurteilen zu können?

## Dashboard

Beschreibt:

- Datenquelle,
- verwendete Panels,
- dargestellte Messgrößen,
- gewählte Zeiträume,
- Grenzwerte/Zustände,
- mindestens eine echte Datenauswertung.

Mögliche Auswertungen:

- Mittelwerte
- Minimum/Maximum
- Trends
- Grenzwertüberschreitungen
- Ereignisse
- Aktorzustände

Legt exportierbare Dashboard-Konfigurationen nach Möglichkeit ebenfalls in diesem Verzeichnis ab.
